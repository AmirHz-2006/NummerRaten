# 🎮 Zahlenratespiel mit GUI

Ein interaktives Zahlenratespiel mit grafischer Oberfläche (Tkinter), Schwierigkeitsstufen und Versuchszähler.

---

## 🚀 Funktionen

- Zufallszahl zwischen definierten Bereichen (je nach Schwierigkeitsgrad)  
- Schwierigkeitsstufen: Einfach (1–50), Mittel (1–100), Schwer (1–200)  
- Eingabeprüfung und Fehlermeldungen  
- Anzeige der Anzahl der Versuche  
- Möglichkeit, die richtige Zahl anzuzeigen  
- Neustart des Spiels jederzeit möglich  

---

## 📦 Technologien

- Python 3  
- Tkinter (GUI)  
- random  
- messagebox  

---

## 📁 Projektstruktur


├── guess_number_game.py


---

## 🧑‍💻 Bedienung

- Beim Start erscheint ein GUI mit Eingabefeld und Buttons  
- Der Benutzer gibt eine Zahl ein und klickt auf „Raten“  
- Rückmeldung erfolgt direkt im Fenster  
- Nach Erreichen der maximalen Versuche oder richtigem Tipp wird das Spiel beendet  
- „Antwort zeigen“ zeigt die gesuchte Zahl  
- „Neues Spiel“ startet das Spiel neu  

---

## 📌 Hinweise

- Die Eingabe muss eine gültige Zahl im Bereich sein  
- Die Anzahl der Versuche hängt vom Schwierigkeitsgrad ab  
- GUI ist nicht skalierbar (feste Fenstergröße)
